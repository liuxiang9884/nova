# sz_45 / Ryzen 9 9950X 当前 set 对比（R9）

本次新增三轮优化，最终保留延迟分配页池和稠密叶按需初始化，撤回分组布局。实验在 `benchmark` 分支；过程、全部轮次与退步见 [LAYOUT_OPTIMIZATION.md](LAYOUT_OPTIMIZATION.md)，此前结果见 [RESULTS-R6.md](RESULTS-R6.md)。

## 环境与口径

- 指定机器 `sz_45` / 主机名 `dctp` / Ryzen 9 9950X，固定CPU 8，同胞24，该CCD L3为32 MiB；不是9950X3D。
- 被测算法源码 `e1aaeaaecf43ce112d920e9a9dd3918a4801e3c8`，开始时间 `2026-09-18T20:50:23+08:00`。后续只补测试及文档。
- GCC13.3.0，C++20，Release `-O3 -DNDEBUG -mavx2 -mpopcnt`；Abseil20260107.1#3，Benchmark1.9.5，vcpkg manifest baseline `114d9fe62faf35856b45cf55cb93b57028a45d63`。
- 四容器、三标准规模、五操作、每项5次重复，0.1s目标计时，random interleaving，取CPU ns/op中位数。数据/查询/删除序列和编译选项统一。
- 排除数据生成、构造、准备及销毁；radix slab/叶分配、初始化、转换、移动与删除释放均计时。作者节点池在构造时预分配并排除，保持原口径，没有声称公平化allocator或端到端成本。
- 保留powersave、CPU scaling和ASLR，未隔离整核/清cache；R9标准规模最大CV6.79%（1K未命中），千万最大0.45%。全部样本保留；另做10次未命中补测，1K未命中R9比R6慢约10.3%，见逐轮报告。
